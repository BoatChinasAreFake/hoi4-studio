# Grand Duchy Rising (example mod built with HOI4 Studio)

An additive Luxembourg overhaul for Hearts of Iron IV, generated by `tools/modbuilder/grandDuchy.ts`
using the suite's own generators (focus-tree script, character script, BOM-safe localisation,
descriptor validator, Tarjan deadlock analysis).

## Contents
- 36-focus national focus tree (industry / military / finance branches, a 3-way mutually exclusive
  strategic choice: Armed Neutrality, Benelux Pact, Western Alignment, then a capstone)
- 17 national ideas / timed ideas, 7 decisions in a custom category, 11 events (2 random MTTH events)
- 2 corps commanders and 3 advisors, scripted effects/triggers, an `on_startup` hook
- English localisation (UTF-8 BOM)

## Install
Copy `mods/grand_duchy_rising/` and `mods/grand_duchy_rising.mod` into
`Documents/Paradox Interactive/Hearts of Iron IV/mod/`, enable it in the launcher, and play as Luxembourg.

## Load safety
No vanilla file is overridden and no map/history/gfx/interface/sound data is touched. Every file and
identifier is `GDR_`/`gdr.`-prefixed. `npx vitest run tests/mod_grand_duchy.test.ts` verifies brace balance,
BOM, localisation coverage, id uniqueness, cross-references and focus-tree reachability.

**Not verified in-game:** the build environment has no HOI4 install, so the mod has not been launched.
Check `Documents/Paradox Interactive/Hearts of Iron IV/logs/error.log` after first launch.

## Rebuild
```bash
npm run mod:build
```
